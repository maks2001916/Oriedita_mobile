## 📱 **Использование в приложении**

### **1. Инициализация**
```kotlin
class MainActivity : AppCompatActivity() {
    private lateinit var resourceManager: AndroidResourceManager
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        resourceManager = AndroidResourceManager(this)
        
        // Установка языка (по умолчанию английский)
        resourceManager.setLanguage(AndroidResourceManager.LANGUAGE_ENGLISH)
    }
}
```

### **2. Переключение языков**
```kotlin
// Английский язык
resourceManager.setLanguage(AndroidResourceManager.LANGUAGE_ENGLISH)
val englishIconName = resourceManager.getIconName("line_input")        // "Line Input"

// Русский язык
resourceManager.setLanguage(AndroidResourceManager.LANGUAGE_RUSSIAN)
val russianIconName = resourceManager.getIconName("line_input")        // "Ввод линий"

// Японский язык
resourceManager.setLanguage(AndroidResourceManager.LANGUAGE_JAPANESE)
val japaneseIconName = resourceManager.getIconName("line_input")      // "線分入力"
```

### **3. Получение ресурсов**
```kotlin
// Названия иконок
val iconName = resourceManager.getIconName("line_input")

// Подсказки
val tooltip = resourceManager.getTooltip("line_input")

// Горячие клавиши
val hotkey = resourceManager.getHotkey("line_input")

// Текст помощи
val helpText = resourceManager.getHelpText("line_tool")
```
